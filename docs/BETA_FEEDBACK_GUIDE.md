# Beta Feedback Guide

Use this guide when expert colleagues test the EL Lesson Alignment Tool with real lesson materials.

## What To Send Back

For each tested lesson, collect:

- Run ID from the app output.
- Grade band, content area, lesson goal, and ELPAC focus.
- Whether the submitted lesson was prose, bullets, numbered steps, or table-like.
- The original lesson, with no student-identifiable information.
- The aligned output.
- The visual packet images, if generated.
- Notes using the review questions below.

## Fast Review Rubric

Score each area from 1 to 4.

1 = not usable yet  
2 = partially useful but needs correction  
3 = useful with minor edits  
4 = ready for a teacher to use

| Area | Reviewer Question |
| --- | --- |
| Same-format output | Did the aligned lesson preserve the teacher's original headings, sequence, and format? |
| CA ELD fit | Do the language supports match the CA ELD expectations and proficiency range? |
| Language demand | Is it clear what students must say, do, or write to show content learning? |
| ELPAC 1 access | Do Level 1 supports help students enter the same task without lowering the thinking? |
| ELPAC 3 access | Do Level 3 supports extend precision, evidence, interaction, or explanation? |
| Teacher usability | Could a content-area teacher use the additions tomorrow without extra translation? |
| Student-friendly criteria | Are success criteria clear, accurate, and tied to both content and language? |
| Feedback moves | Are teacher prompts specific enough to support language growth during the lesson? |
| Overreach | Did the tool rewrite too much, add generic filler, or change the lesson's intent? |
| Safety | Did the tool avoid asking for or exposing student-identifiable information? |
| Visual packet | Is the generated packet readable, useful within two minutes, and faithful to the checked alignment? |

## Best Feedback Format

```text
Run ID:
Grade/content:
Lesson goal:
Overall score, 1-4:

What worked:

What was inaccurate, generic, or misaligned:

Where the tool changed too much or too little:

Missing language supports or scaffolds:

Suggested better output language:

Did the visual packet help within 2 minutes?

Would a content teacher use this? Why or why not?
```

## What To Watch Closely

- The tool should align one lesson, not build a unit plan.
- The first output should be the teacher's lesson in a recognizable form, not a report.
- Supports should keep the same cognitive expectation for English learners.
- Sentence frames and teacher moves should connect to the actual lesson task.
- CA ELD references should stay grounded in the retrieved Part I, Part II, and PLD bundle.
- Generated model language should be short, original, and classroom-usable.

## Privacy Rule

Do not paste student names, IDs, scores, IEP/504 details, health details, discipline details, rosters, parent contact information, or other student-identifiable data into the beta.
