# Draft CDE Permission Request

Subject: Permission request for free teacher beta using CA ELD Standards

Hello,

I am requesting permission to use California English Language Development Standards content in a free teacher-facing beta called EL Lesson Alignment Tool.

The tool helps teachers paste an existing lesson, unit, or task and receive the same material back with light CA ELD alignment additions. The product is intended as a free instructional support tool for educators. It is not affiliated with, sponsored by, or endorsed by the California Department of Education.

The beta uses:

- CA Content Standards search, English Language Development, Part I
- CA Content Standards search, English Language Development, Part II
- California English Language Development Standards publication for proficiency-level context

The product will:

- Attribute CDE and the California State Board of Education as the source of the CA ELD Standards.
- Avoid use of CDE logos, seals, or branding.
- Preserve official standard text separately from app-created summaries.
- Avoid implying CDE endorsement.
- Keep the tool free for teachers during the beta.

Please let me know whether this use is permitted, whether additional attribution language is required, or whether any additional license or written permission is needed.

Thank you,

Matt Messinger
