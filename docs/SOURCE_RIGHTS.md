# Source Attribution and Rights

## Free Beta Source Notice

This free beta uses California English Language Development Standards published by the California Department of Education and adopted by the California State Board of Education. This tool is not affiliated with, sponsored by, or endorsed by CDE.

## Product Posture

- Launch posture: free teacher beta.
- The app should not imply CDE affiliation, sponsorship, approval, or endorsement.
- The app should not use CDE logos, seals, or branding.
- Official standard text is stored in `standardText` and should not be edited in place.
- App-created summaries and explanations belong in separate fields such as `teacherFriendlySummary`.
- This document is product documentation, not legal advice. Counsel or CDE feedback can supersede this posture.

## Implementation Rules

- Every imported official CA ELD record must include source name, source URL, copyright owner, import date, and immutable standard text.
- Teacher-facing output should cite standards by identifier and use short app-authored explanations.
- If official wording is shown, it must be represented as source text, not as model-generated language.
- Any future paid/commercial packaging should pause for legal review before using embedded official text.
